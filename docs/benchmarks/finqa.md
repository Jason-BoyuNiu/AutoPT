# FinQA

[调研总览](README.md)

EMNLP 2021，来自财报正文和表格，论文报告 8,281 条由金融专业人员编写的问答，并标注支持证据、推理程序与执行结果。官方基线先检索财报证据，再生成可执行程序。[论文](https://aclanthology.org/2021.emnlp-main.300/) · [官方仓库](https://github.com/czyssrs/FinQA)

## 题目精读

**论文图 1。** 比较 2005、2006 两期的归属股票数量变化。每期要从涉及的金额除以该期加权平均期权公允价值，再相减。图中示例使用 `9413 / 20.01` 与 `8249 / 9.48`，得到约 −400。只取表格中的差值会漏掉分母，交换年份则改变符号。[论文图 1](https://aclanthology.org/2021.emnlp-main.300.pdf)

**字段层面。** 财报部分与 QA 目标是不同对象。训练或诊断时可查看证据标注，但在端到端测试时要让模型从财报中定位信息。这样才能区分检索错、数值单位错、公式错与执行错。[数据与官方说明](https://github.com/czyssrs/FinQA/tree/main/dataset)

## 判卷与小模型依据

官方协议区分执行结果和程序准确率。金标准证据、全报告检索、模型输出数值和执行程序属于不同设置。EACL 2026 实验使用 SmolLM-1.7B、Phi-3-mini 比较真实和合成训练数据，并执行模型生成的 Python，属于小模型后训练参考，复现时要采用其设置或另报官方 FinQA 指标。[小模型后训练论文](https://aclanthology.org/2026.eacl-industry.51/)

## 用在 AutoPT

作为金融推理方向的目标任务，与 TAT-QA 进行跨题库测试。预先按报告或文档分组检查重叠，统一单位和表格序列化。离线可以保留专用 DSL 评分，使用自由 Python 的设置另备执行环境。作者列出 CodaLab 入口，提交机制可用性待验证。
